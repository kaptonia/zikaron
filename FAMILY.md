# ZIKARON family components

Shared components of the three desktop apps of the family (ZIKARON, GALEED, ERAVON). Each component carries a family version number. A project that changes a component bumps its number at release; the others see the higher number, read the diff between the two releases of that project, and decide what to pull. The number records what was done, not bytes; it moves only at release.

This list is ZIKARON's, as of release 0.1.4. Paths are relative to this repository at that release. The machine-readable form is `family-components.json`; the literals a port must replace are in `crates/app/family-literals.json`.
